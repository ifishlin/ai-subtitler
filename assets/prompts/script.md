# 寫一份短影音文案

從底下的素材寫出一份 {length.limit_seconds} 秒的短影音文案。

**全部用{language.name}**——台詞、卡片上的字、角色名稱，一個簡體字都不行。
有門在檢查，逐字判。

畫面怎麼配、卡片怎麼畫，在 `visual.md`。這份只談**話怎麼說**。

## 先讀，再想，最後才寫

素材裡會有立場不同的媒體。**先找出他們彼此矛盾、或都沒提的地方**——
觀點就長在那裡。

不要從「最重要的事實」開始寫。最重要的事實，五家媒體都講過了，觀眾也看過了。
你要寫的是**他們都沒說的那句話**。

三種地方最容易長出觀點：

- 兩邊拿出**互相衝突的數據**（那通常表示他們算的不是同一件事）
- 一件事被**不同的方式解讀**
- 所有人都在吵 A，**沒有人在問 B**

## 觀點的標準

一句話說得完，而且**素材裡沒有任何一篇這樣寫過**。

```
不算觀點   「國債破了四十兆」                 這是事實，人人都報了
不算觀點   「A 說漲、B 說沒漲」               這是彙整
算觀點     「兩邊都對，因為算的不是同一件事」   這是判斷
```

## 結構

每一句都要標角色，四種：{structure.roles}

```
起   先給觀眾以為自己知道的版本
承   把它推到底 —— 讓觀眾更確信
轉   推翻它 —— 必須在前三分之一出現，晚了留不住人
合   這件事怎麼碰到觀眾的生活，最後一句回答「所以關我什麼事」
```

程式會檢查四種都在、順序沒亂、轉出現在前 {structure.turn_before:pct}。
**它檢查不了那個轉夠不夠有力**——那是你的事。

判準：**轉之後，觀眾對同一批事實的理解要不一樣了。** 只是補充細節不算轉。

### 結論一定要落在市井小民身上

不管題目多大——戰爭、國債、外交、氣候——最後一句都要回到**一般人身上**。
不是「這件事很重要」，是**「你會在哪裡遇到它」**。

```
不行   「這是全球經濟的重大警訊。」        關我什麼事？
不行   「各國政府必須正視這個問題。」      那是給政府看的
可以   「你不會收到帳單，你會收到分期版。」
可以   「加油站那本帳不會被審計，而那一本是你在付。」
```

判準：把最後一句念給一個不看新聞的人聽，**他要能立刻知道這跟自己有關**。

做不到的時候，通常是因為前面的落地做得不夠——回去找那個「錢、時間、健康、
安全」的接觸點，不要在結論硬凹。

### 「一般人」是誰，題目上已經寫著了

題目頁有一欄「說給誰聽」，**用那一欄，不要自己重新判斷**。

底下那張對照表是用來**填那一欄**的，不是每次寫稿時重猜一次。
表按關鍵字比對，而關鍵字不知道事情：「科技巨頭買下好萊塢」對到科技那一列，
變成「工作可能被取代的人」——實際上那題是講給**付串流訂閱、看新聞的人**聽的。

### 對照表（拿來起頭，不是拿來當答案）

```
國債、通膨、電費   → 每個要付帳單的人
股市、財報、升息   → 股民、有退休金帳戶的人
戰爭、外交         → 加油、繳稅、家裡有役齡孩子的人
醫療、長照         → 排隊看病的人、照顧家人的人
氣候、天災         → 住在會淹的地方、保費會漲的人
科技、AI           → 工作可能被取代的人、電費在漲的人
```

股民也是市井小民，只是接觸點是**帳戶餘額**，不是水電費。所以股市題目的結論
落在「你的持股」上就是落地了，不用硬扯到菜價。

**不要挑最大的那群，挑最痛的那群**——被影響最深的人，才會分享。

## 語氣

預設詼諧，但**題材決定語氣**。死亡、疾病、災難、戰爭傷亡——**不要開玩笑**。
放不下來的語氣不是風格，是習慣性動作。這種題目改成克制，力氣放在清楚上。

詼諧要來自**比喻**，不是來自嘲笑。

```
好   「左口袋欠右口袋八萬塊，然後宣布自己破產。」
壞   拿罹難人數或病人開玩笑
```

## 每一句的寫法

```
say     台詞。口語，不是書面語。念得出來的
role    {structure.roles} 其中一個
show    這句話的時候畫面上是什麼（看 visual.md）
from    出處。如果是你自己的判斷，寫「觀點」
```

- **每句 {caption.per_row} 個中文字以內**——直式字幕一行的寬度
- **數字要念出來**：「四十兆」不是「40兆」，「百分之三點四」不是「3.4%」
- 陳述事實的句子**一定要有出處**，而且要指得回素材裡的某一篇
- 標「觀點」的是你自己的判斷，不需要出處，但**不能拿來夾帶沒有根據的事實**

## 數量

```
句數      有旁白 {length.lines} 句　無旁白 {length.lines_silent} 句
觀點句    約一半
長度      {length.limit_seconds} 秒
```

有旁白算唸的速度（每秒 {pace.spoken_per_second} 字），無旁白算讀的速度
（每秒 {pace.read_per_second} 字）。**無旁白每句還有下限
{pace.least_seconds} 秒**——再短的句子也要讓人讀完。第一次做無旁白版
我用保守的每秒 3.7 字，結果 108 秒。

不用自己算，寫完程式會告訴你。

## 輸出格式

只輸出 JSON，不要別的。**圖和影片段落用素材清單上的編號，不要寫檔名**：

```json
{
  "view": "一句話講完你的觀點",
  "tone": "詼諧 或 克制",
  "lines": [
    {"say": "台詞", "role": "角色", "show": "自製：畫面說明",
     "card": {"kind": "word", "title": "…"}, "from": "出處 或 觀點"},

    {"say": "台詞", "role": "角色", "show": "示意：這張圖是什麼",
     "pic": "P18", "from": "出處"},

    {"say": "台詞", "role": "角色", "show": "影片：這段在演什麼",
     "clip": "C3", "from": "出處"}
  ]
}
```

`P18`、`C3` 就是上面素材清單裡那個編號，照抄。**寫檔名一定會錯**——
編號查得到，檔名要記，而記錯的檔案往往真的存在（是別的題目的），
看起來完全合理。

`clip` 只寫編號，起訖秒數由程式從清單填。

## 最後檢查

- [ ] 觀點是素材裡沒有的嗎？還是我只是換句話說？
- [ ] **轉之後，觀眾對同一批事實的理解真的不一樣了嗎？**
- [ ] 每一句陳述事實的，都指得回某一篇嗎？
- [ ] 這個題材適合開玩笑嗎？
- [ ] 這題目最直接影響的是哪一群人？結論是寫給他們聽的嗎？
- [ ] 最後一句，那群人聽了會知道跟自己有關嗎？

長度、字數、比例、有沒有出處、四段結構——**程式會算，不用自己數**。
