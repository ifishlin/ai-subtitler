# 寫一份短影音文案

你要從底下的素材寫出一份 90 秒的中文短影音文案。

## 先讀，再想，最後才寫

素材裡會有立場不同的媒體。**先找出他們彼此矛盾、或都沒提的地方**——
觀點就長在那裡。

不要從「最重要的事實」開始寫。最重要的事實，五家媒體都講過了，
觀眾也看過了。你要寫的是**他們都沒說的那句話**。

三種地方最容易長出觀點：

- 兩邊拿出**互相衝突的數據**（那通常表示他們算的不是同一件事）
- 一件事被**不同的方式解讀**
- 所有人都在吵 A，**沒有人在問 B**

## 觀點的標準

一句話說得完，而且**素材裡沒有任何一篇這樣寫過**。

```
不算觀點   「國債破了四十兆」            —— 這是事實，人人都報了
不算觀點   「A 說漲、B 說沒漲」          —— 這是彙整
算觀點     「兩邊都對，因為算的不是同一件事」 —— 這是判斷
```

## 結構

```
鋪陳    先給觀眾以為自己知道的版本
翻轉    推翻它 —— 必須在前三分之一出現，晚了留不住人
落地    這件事怎麼碰到觀眾的生活
結論    一句話，回答「所以關我什麼事」
```

### 結論一定要落在市井小民身上

不管題目多大——戰爭、國債、外交、氣候——最後一句都要回到**一般人身上**。
不是「這件事很重要」，是**「你會在哪裡遇到它」**。

```
不行   「這是全球經濟的重大警訊。」          —— 關我什麼事？
不行   「各國政府必須正視這個問題。」        —— 那是給政府看的
可以   「你不會收到帳單，你會收到分期版。」   —— 落在你身上
可以   「加油站那本帳不會被審計，而那一本是你在付。」
```

判準：把最後一句念給一個不看新聞的人聽，**他要能立刻知道這跟自己有關**。

做不到的時候，通常是因為前面的落地做得不夠——回去找那個「錢、時間、
健康、安全」的接觸點，不要在結論硬凹。

### 「一般人」是誰，看題目而定

不是每個題目的觀眾都是同一批人。**先想清楚這題的「他」是誰**，再寫結論。

```
國債、通膨、電費   → 每個要付帳單的人
股市、財報、升息   → 股民、有退休金帳戶的人
戰爭、外交         → 加油、繳稅、家裡有役齡孩子的人
醫療、長照         → 排隊看病的人、照顧家人的人
氣候、天災         → 住在會淹的地方、保費會漲的人
科技、AI           → 工作可能被取代的人、電費在漲的人
```

股民也是市井小民，只是他的接觸點是**帳戶餘額**，不是水電費。所以股市題目
的結論落在「你的持股」或「你的勞退」上，就是落地了，不用硬扯到菜價。

寫之前先問一句：**這題目最直接影響的是哪一群人？** 結論就寫給他們聽。

判斷的時候不要挑最大的那群，挑**最痛的那群**——被影響最深的人，才會分享。

## 語氣

預設詼諧，但**題材決定語氣**。

死亡、疾病、災難、戰爭傷亡——**不要開玩笑**。放不下來的語氣不是風格，
是習慣性動作。這種題目改成克制，把力氣放在清楚上。

詼諧要來自**比喻**，不是來自嘲笑。

```
好   「左口袋欠右口袋八萬塊，然後宣布自己破產。」
壞   拿罹難人數或病人開玩笑
```

## 每一句的寫法

一句台詞配一個畫面。每一句都要寫清楚：

```
say    台詞。口語，不是書面語。念得出來的
show   這句話的時候畫面上是什麼
from   這句的出處。如果是你自己的判斷，寫「觀點」
```

規則：

- **每句 13 個中文字以內**——直式字幕一行的寬度
- **數字要念出來**：「四十兆」不是「40兆」，「百分之三點四」不是「3.4%」
- 陳述事實的句子**一定要有出處**，而且要指得回素材裡的某一篇
- 標「觀點」的是你自己的判斷，不需要出處，但**不能拿來夾帶沒有根據的事實**

## 畫面的節奏

全部都是自製卡片的影片很悶，觀眾會滑掉。所以要**穿插真實的影像**——
新聞畫面、現場照片、當事人的臉。

```
引用畫面   約佔總長 25%
出現節奏   每三分之一的時間至少一次
```

90 秒的話，大約是這樣：

```
0–30 秒    自製卡片鋪陳  →  中間插一段影像
30–60 秒   翻轉，自製為主  →  再插一段
60–90 秒   落地和結論     →  再插一段
```

每段引用約 7 到 8 秒，三段加起來 22 秒左右。

**放在哪裡有講究**：引用畫面要放在**你需要證據的那一句**，不是隨便找地方
填。講到死傷就給現場、講到誰說了什麼就給那個人在說、講到數字就給新聞台
的圖表。它的作用是「這不是我編的」，不是裝飾。

25% 是上限不是目標。如果某一段找不到合適的畫面，寧可少放——**別人的畫面
佔比一高，YouTube 會判定內容不是你的**，那條規則罰的是整個頻道。

### 實拍要在寫的時候就選好哪一張

`show` 只寫「真實：變電所」是不夠的。**那一句要用哪個檔案，寫的時候就決定**，
記在 `pic` 欄位：

```json
{"say": "你家跟機房共用同一條線。", "show": "真實：住宅區的輸電塔",
 "pic": "assets/photos/題目名/36433653.jpg", "from": "觀點"}
```

分開做會斷成兩半：**寫的人沒看過有哪些圖，挑圖的人不知道那句話為什麼要那張圖。**
第一次做就是這樣——文案寫「真實：變電所／輸電塔」，實際挑檔案是幾天後做影片時
才發生的事。

而且分開會讓標籤說謊。我把 CNBC 的渦輪機廠畫格標成「機房」，因為寫的時候
只是憑想像描述。**標籤跟圖不符比沒有標籤更糟**，因為那個標籤會被抄進燒錄。

寫完程式會檢查每一句實拍有沒有指定圖、檔案在不在。

**但程式不會幫你看那張圖。** 選之前要真的打開來看，不能照搜尋詞挑——
搜尋詞說的是你想要什麼，不是你拿到什麼：

```
搜 electricity bill    回來的是牆上的白色配電箱
搜 transmission tower  回來的是一條有樹的馬路，電線幾乎看不見
```

這兩張我都選了，直到把它們排在一起看才發現。挑圖之前先把候選排成一張
接觸表看過——那本來就是 `contact_sheet` 存在的理由。

### 實拍和自製怎麼分

寫 `show` 的時候，開頭決定它算哪一種：

```
自製：…      我們畫的卡片、圖表、示意動畫
示意：…      圖庫照片（Pexels）
真實：…      Wikimedia Commons，有名字的人事地
新聞畫格：…   從這個題目的影片剪的
```

**只有「自製：」開頭的算自製，其餘都算實拍。** 程式就是這樣數的，寫錯開頭
會讓比例算錯——第一次做的時候判斷邏輯還在找舊詞彙，一支滿是實拍的文案
被報成 0%。

### 哪些句子該用實拍

實拍要放在**有東西可看**的句子上。**在講道理的句子用卡片**——它們沒有畫面，
硬配一張照片只是填空。

```
該用實拍   「你的電費帳單，去年變貴了。」        有東西可拍
          「大家都說，是資料中心害的。」        給機房畫面
          「你家跟機房共用同一條線。」          給電線桿

該用自製   「因為他們算的不是同一件事。」        這是判斷，沒有畫面
          「兩邊都有數據。誰在說謊？」          這是提問
          「該問的是：你住在哪裡。」            這是結論
```

第一版我把「有些州漲超過兩成」和「該問的是你住在哪裡」都配了照片，
比例衝到 38%，超過上限。換成卡片之後降到 32%，而且**那兩句本來就更適合
用圖表講**。

## 數量

```
句數      18–22 句
觀點句    約一半
自製畫面  約 68–75%
實拍畫面  25%，上限 35%，分三段出現
```

長度看有沒有旁白，兩者差得不少：

```
有旁白   中文每秒約 4.5 字   90 秒 ≈ 400 字
無旁白   每秒約 4.6 字       90 秒 ≈ 410 字，但每句至少要 1.9 秒
```

無旁白的版本**看起來可以塞更多字，實際上不行**——每一句都有下限，因為
再短的句子也要讓人讀完。第一次做無旁白版，我用保守的每秒 3.7 字，
結果 108 秒；壓到 4.6 才進 90 秒內。

不用自己算，寫完程式會告訴你。

## 輸出格式

只輸出 JSON，不要別的：

```json
{
  "view": "一句話講完你的觀點",
  "tone": "詼諧 或 克制",
  "lines": [
    {"say": "台詞", "show": "自製：畫面說明", "from": "出處 或 觀點"}
  ]
}
```

## 最後檢查

寫完自己看一遍：

- [ ] 觀點是素材裡沒有的嗎？還是我只是換句話說？
- [ ] 翻轉出現在前三分之一了嗎？
- [ ] 每一句陳述事實的，都指得回某一篇嗎？
- [ ] 這個題材適合開玩笑嗎？
- [ ] 有沒有哪一句超過 13 個字？
- [ ] 引用畫面有沒有分散在三段裡，而不是擠在一起？
- [ ] 每一段引用，都是那一句真的需要證據嗎？
- [ ] 這題目最直接影響的是哪一群人？結論是寫給他們聽的嗎？
- [ ] 最後一句，那群人聽了會知道跟自己有關嗎？
- [ ] 每個 `show` 都用「自製：／示意：／真實：／新聞畫格：」開頭了嗎？
- [ ] 用實拍的那幾句，真的有東西可看嗎？還是在講道理？
- [ ] 每一句實拍都填了 `pic` 或 `clip` 嗎？
- [ ] 每一張圖的 `caption` 都跟 `show` 對得上嗎？（並排讀，不一致就是選錯）
- [ ] 每一句實拍都打開來看過、填了 `seen` 嗎？
- [ ] 會動的畫面有沒有佔到實拍的一半？
