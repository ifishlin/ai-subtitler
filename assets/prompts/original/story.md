# 寫一份說故事的短影音文案

**全部用{language.name}**——台詞、卡片上的字、角色名稱，一個簡體字都不行。
有門在檢查，逐字判。

有些題目不是拿來論證的。失竊案、災難、一個人的遭遇——**觀眾要的是懸念，
不是判斷**。

論證型的片型在 `script.md`。這一份不一樣，差別先講清楚：

```
新聞報導   起 → 承 → 轉 → 合      先讓你相信，再推翻，然後告訴你關你什麼事
說故事     場景 → 事件 → 疑點 → 懸念  先讓你在場，再讓你困惑
```

## 為什麼要分開

梅西納失竊案第一版是用論證型寫的。論證型要求「轉」出現在前三分之一，
所以前三十秒變成壓縮的說明——時間、人數、警力、封路，一句接一句趕過去。

**而那些正是應該慢慢看的東西。** 十五萬人擠在市中心、市郊那棟樓空無一人、
三分鐘、兩片畫小心地靠在矮牆上——那是現場，不是背景資料。

## 場景

**先讓觀眾站在那裡。** 時間、地點、那天發生什麼。

不要急著解釋為什麼重要。至少 {structure.least_per_role.場景} 句，
沒有時間上限——這一段慢，後面才有得快。

```
好   「八月十五號晚上八點四十七分。」
     「市中心擠了十五萬人。」
     「而市郊那棟樓，空的。」

壞   「這起竊案暴露了博物館的保全漏洞。」   ← 這是結論，不是場景
```

## 事件

**發生了什麼，照順序。** 不要倒敘、不要預告後面的疑點。

至少 {structure.least_per_role.事件} 句。動詞要具體：剪開、撬開、帶走。
不要「進行了竊盜行為」。

## 疑點

**這一段最長**，至少 {structure.least_per_role.疑點} 句，因為它才是這種片子
真正在做的事。

一個一個擺出來，**不要解釋，不要下結論**。觀眾自己會開始想。

```
好   「三分鐘，五片畫全部帶走。」
     「那扇側門，是少數沒裝警報的。」
     「畫作自己的警報響了。」
     「警衛把它關掉了。」

壞   「種種跡象顯示可能有內應。」   ← 這是替觀眾想完了
```

**最好的疑點是互相矛盾的兩件事。** 警報有效 vs 警報被關掉；辛苦拆下五片
vs 丟下兩片。

## 懸念

**不要給答案。** 至少 {structure.least_per_role.懸念} 句。

這種題目通常真的沒有答案，硬給一個就變成假的。結尾是一個**更好的問題**，
或者一件所有人都忽略的事。

```
好   「擋住小偷的最後一道，是一個人的判斷。」
好   「那個警衛不知道是哪一次。」
壞   「這起案件警示我們保全的重要性。」
```

「觀眾」是誰，題目頁的「說給誰聽」那一欄寫著，用那一欄。

**可以落在觀眾身上，但用連結不用說教**：那個警衛忽略警報的理由，跟你忽略
詐騙簡訊的理由是同一個。

## 畫面

```
外部素材   佔總長 {borrowed.aim:pct}（下限 {borrowed.least:pct}、上限 {borrowed.most:pct}）
影片段落   至少佔外部素材的 {borrowed.clip_least:pct}
```

**比論證型再高一截**，因為故事要氣氛，而氣氛只能靠畫面。故事片本來就在講
別人的事，**我們的貢獻是選擇和順序**，不是論證。

下限跟論證型同一條：**卡片最多一半**。故事片如果一半以上是字卡，
那個故事沒有被看到，只是被讀到。同一張照片可以用在好幾句上，所以湊得到。

其餘（卡片字彙、tone、fit、影片段落怎麼挑）跟論證型一樣，看 `visual.md`。

## 輸出格式

只輸出 JSON，不要別的。**圖和影片段落用素材清單上的編號，不要寫檔名**：

```json
{
  "view": "一句話講完你的觀點",
  "tone": "詼諧 或 克制",
  "lines": [
    {"say": "台詞", "role": "角色", "show": "自製：畫面說明",
     "card": {"kind": "word", "title": "…"}, "from": "出處 或 觀點"},

    {"say": "台詞", "role": "角色", "show": "示意：這張圖是什麼",
     "pic": "P18", "from": "出處"},

    {"say": "台詞", "role": "角色", "show": "影片：這段在演什麼",
     "clip": "C3", "from": "出處"}
  ]
}
```

`P18`、`C3` 就是上面素材清單裡那個編號，照抄。**寫檔名一定會錯**——
編號查得到，檔名要記，而記錯的檔案往往真的存在（是別的題目的），
看起來完全合理。

`clip` 只寫編號，起訖秒數由程式從清單填。

## 每一句的寫法

```
say     台詞。{caption.per_row} 字內
role    {structure.roles} 其中一個
show    畫面（看 visual.md）
from    出處。自己的判斷寫「觀點」
```

長度 {length.limit_seconds} 秒，無旁白 {length.lines_silent} 句。
