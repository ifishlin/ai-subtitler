# 看一張圖，判斷它是不是那句話要的

你會拿到一張圖、一句台詞、和那句台詞說這張圖是什麼。
回答**這張圖裡有沒有那個東西**。

## 為什麼要問

搜尋 `electricity bill` 回來一張牆上的白色配電箱。圖庫是拆成單字比對的：
`electricity` 對到說明裡的 `Electrical`、`bill` 對到 `billing`，兩個字都在，
所以它回傳了。**它自己的說明白紙黑字寫著 `fuse box`。**

那張圖被標成「示意：帳單特寫」，通過了「有沒有指定圖」「檔案在不在」兩道檢查，
一路走進成品。**程式檢查得了檔案在不在，檢查不了像不像。**

同一批還有一張標成「真實：住宅區的輸電塔」，實際上是一條有樹的馬路，
電線幾乎看不見——而它扛的那句話是「你家跟機房共用同一條線」。

## 判準

只問一件事：**一個不知道標籤的人，看到這張圖，會不會說出那句話說的東西？**

```
可以   標「電表特寫」，畫面是一排電表
可以   標「住家後面的高壓電塔」，畫面是房子後面立著一座電塔
不行   標「帳單特寫」，畫面是牆上的配電箱          ——  是電力設備，不是帳單
不行   標「住宅區的輸電塔」，畫面是一條有樹的馬路   ——  電線在，但不是主角
```

第二條特別重要：**東西在畫面裡不等於它是畫面的主角。** 那句話要說服人，
圖就得一眼看得出來。

## 出處也要看

如果標籤說是某台的新聞畫面，畫面上應該找得到那台的台標或字卡。找不到就說。

## 回答格式

```json
{"ok": true,  "why": "一排紅色電表，正面特寫"}
{"ok": false, "why": "是牆上的配電箱和電表，不是帳單", "instead": "帳單特寫"}
```

`why` 寫**你在畫面上看到什麼**，不要重複標籤。
不確定就回 `false`——**選錯的代價是成品有一張說謊的圖，重挑的代價是一次搜尋。**
