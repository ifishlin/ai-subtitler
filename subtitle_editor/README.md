# 字幕校對網頁

對 **已完成的成品** 做字幕校對，然後選擇性地重新燒錄。
完全不改動 `main.py` 或 `src/`，也不重跑 pipeline。

## 啟動

```bash
.venv/bin/python subtitle_editor/server.py
```

然後開 <http://127.0.0.1:8000>。關掉終端機就結束。

第一次啟動要轉一支瀏覽器可播的 proxy（約 45 秒），之後啟動只要幾秒。
指定其他影片：`server.py /path/to/video.mp4`，換 port：`--port 8100`。

啟動後可以直接在網頁左上角的選單切換要校對哪一次的輸出，
不需要重開 server。切換時若有未儲存的修改會先提醒。
每支影片的 proxy 和波形分開快取，所以切回去不用重新轉檔。

也可以在啟動時就指定目錄：

```bash
.venv/bin/python subtitle_editor/server.py --output output_v2
```

校對進度按輸出目錄分開存（`editor_cache/review_<目錄名>.json`），兩個版本不會互相干擾。

## 讀什麼、寫什麼

| | 檔案 | 用途 |
|---|---|---|
| 讀 | `work/source_*.mp4` | 乾淨的原片（成品的字幕是燒進畫面的，不能當底片） |
| 讀 | `output/subtitles_zh.srt` | 要校對的字幕 |
| 讀 | `output/transcript_raw.json` | Whisper 原文，用來顯示 diff |
| 讀 | `output/transcript.json` | Qwen 校正後的文字 |
| 讀 | `output/ai_visuals.json` | 圖卡位置（時間軸顯示、重新燒錄時沿用） |
| 寫 | `output/subtitles_zh.reviewed.srt` | 校對後的字幕 |
| 寫 | `output/final_reviewed.mp4` | 按「重新燒錄」才產生 |
| 寫 | `editor_cache/` | proxy、波形、校對進度（可安全刪除） |

原始的 `subtitles_zh.srt` 和 `final.mp4` 永遠不會被覆寫。

## 界面

**左邊** proxy 影片，字幕即時疊在上面 —— 改字馬上看到效果，不需要重新編碼。
下面是時間軸：波形、字幕分佈、字幕空白區、圖卡位置。

**點時間軸任一處**，影片跳到那裡，右邊列表同時選中並捲到對應的那一段字幕
（那個時間點沒有字幕時選最接近的一段；若該段正被篩選隱藏，會自動切回「全部」）。
**按住拖曳**可以來回掃描找位置。

**右邊** 字幕列表，依時間排序。每一段顯示：

- 目前文字（可直接編輯）
- 與 Whisper 原文的字元級 diff（<del>紅色</del>是 Whisper 說的、<ins>綠色</ins>是後來改的）
- 標籤：`Qwen 改動 n%`（改動大 = 風險高）、`漏聽補句 · 未驗證`（來自 extra-segments sidecar）

顏色代表左側邊框：藍=一般、黃=Qwen 改動大、紫=漏聽補句、綠=已確認。

「漏聽補句」是 Whisper 完全沒聽出來、由 sidecar 補回的句子。這些句子是機器辨識產物，
並非人工逐句確認過，所以標成「未驗證」—— 用「重聽」按鈕可以對照原始語音檢查。

## 快速鍵

不在輸入框時：

| 鍵 | 動作 | 鍵 | 動作 |
|---|---|---|---|
| `空白` | 播放 / 暫停 | `J` `L` | 倒退 / 前進 2 秒 |
| `↑` `↓` | 上一段 / 下一段 | `Enter` | 編輯這一段 |
| `P` | 只播這一段 | `D` | 標記已確認 |
| `R` | 退回 Whisper 原文 | `⌘S` | 儲存 |

在輸入框時：`Enter` 確認並跳下一段、`Esc` 離開、`⌘Enter` 在游標處分割字幕。

## 調整時間長短

每一段字幕下方都有一排時間控制：

```
起 [−] 0:00:59.80 [＋] [設為現在]   終 [−] 0:01:02.30 [＋] [設為現在]   2.50s
```

- `−` `＋` 每按一次動 0.1 秒
- 時間是 **時:分:秒**，和影片播放器一致。可以直接點進去打，
  也接受省略小時的 `1:02.3` 或純秒數 `62.3`，以及 SRT 的逗號小數 `0:01:02,300`
- **「設為現在」** 把時間設成影片目前播放到的位置 —— 最實用：
  播到這句話開始講的瞬間按「起 · 設為現在」，播到講完按「終 · 設為現在」
- 最右邊顯示這段的長度；如果和鄰句時間重疊會轉紅字提示，標題列也會顯示重疊筆數

## 時間重疊

重疊的字幕燒進影片後會同時出現、疊在一起，所以要修掉。
一有重疊，工具列就會出現 **「修正重疊」**：把前一句的結尾縮到後一句開始的位置。
前一句沒有空間可讓時，改成把後一句的開頭往後推。

兩句幾乎完全重疊（例如一句整個包在另一句裡面）無法自動處理，
會回報還剩幾處，那種情況通常是其中一句該刪掉。

手動修的話，把前一句播到該結束的位置按「終 · 設為現在」，或直接按 `−` 縮短。

鍵盤：`,` `.` 調開始時間，`;` `'` 調結束時間，每次 0.1 秒。
（macOS 把 `Control` + 方向鍵佔用於切換桌面，所以不使用那組按鍵。）

## 新增字幕

Whisper 完全沒辨識到、時間軸上根本沒有那一段時，有三種方式補上：

1. **在播放位置插入** —— 把影片播到要補字幕的地方，按工具列的「＋ 在播放位置插入字幕」或按 `N`。
   會插入一段 2.5 秒的空白字幕，游標自動進去，直接打字。
   長度會自動縮到下一段字幕之前，不會重疊。播放頭正好在某段字幕上時，會接在那段之後開始。
   插完用 `⌃←` `⌃→` 微調開始時間、加 `⇧` 微調結束時間。
2. **從空白區插入** —— 時間軸上的紅色缺口會在列表出現一張卡，按「手動加字幕」直接用整個缺口的時間範圍。
   缺口需超過 1.2 秒才會列出。
3. **分割現有字幕** —— 游標放在文字中間按 `⌘Enter`，一段切成兩段，時間按字數比例分配。

如果按 `N` 出現「這個位置沒有空檔可以插入」，表示前後都被字幕占滿了，改用第 3 種方式。

## 重聽

任何一段或任何空白區都有「重聽」按鈕，只對那個時間窗跑 **sensitive 模式** Whisper。

這是刻意設計的：對整片跑 `--sensitive` 會增加錯字（`積淹水` → `積煙水`），
但只對一段街訪或一句可疑的話跑，就能拿到 sensitive 的靈敏度而避開它的副作用。

第一次按會載入 medium 模型，約 30 秒；之後每次幾秒。
結果會顯示 `logprob`（平均對數機率，越接近 0 越有信心）。

- 空白區的結果 → 按「採用」新增一段字幕
- 一般段落的結果 → 按「取代」覆蓋該段文字（時間軸不動，要自己確認是否也要調）

## 重新燒錄

按「重新燒錄」會用 **原片 + 目前字幕 + 既有圖卡** 產生 `output/final_reviewed.mp4`。
呼叫的是 pipeline 現成的 `src/render.py`，所以字幕樣式、圖卡疊法、編碼參數與 `final.mp4` 完全一致。

需要幾分鐘。`final.mp4` 不會被覆蓋。

## 為什麼需要一支後端程式

瀏覽器的沙箱不允許網頁讀寫任意檔案、也不能執行 ffmpeg 或 Whisper。
所以介面在瀏覽器（影片播放、波形、鍵盤操作都是它擅長的），
檔案存取和跑工具由這支你自己啟動的 Python 程式負責，兩邊用 `127.0.0.1` 上的 HTTP 溝通。
沒有對外連線。
