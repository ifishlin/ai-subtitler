## 2. B-roll 是什麼

B-roll = 用來搭配旁白、主持人或主要內容的輔助影片片段。

例如旁白：

> 「現在很多人每天花好幾個小時滑短影音。」

可以搭配：

- 人躺在床上滑手機
- 手指滑手機畫面
- 年輕人看 TikTok / Reels
- 手機特寫
- 通勤族看手機

這些都屬於 B-roll。

在新聞解說影片中，常見做法是：

```text
旁白 / 主持人
    ↓
每 3–6 秒切換一個 B-roll
    ↓
必要時插入新聞原始畫面、截圖、圖表、動畫
```

## 3. 各平台適合的用途

### Envato Elements

適合一次解決大量素材需求：

- B-roll
- Stock photos
- Music
- Sound effects
- Premiere Pro templates
- After Effects templates
- Animated titles
- Infographics
- Map animations
- Icons
- Transitions

**優點：**

- 價格低
- 素材種類非常廣
- 適合剛開始做 YouTube
- 一個訂閱可以處理大部分後製需求

**缺點：**

- 單論真人情境 B-roll，搜尋體驗與素材集中度未必比 Storyblocks 好

---

### Storyblocks

非常適合新聞解說、知識型 YouTube。

典型素材：

- 人滑手機
- 年輕人用 TikTok
- 辦公室工作
- 城市街景
- 超市購物
- 家庭生活
- 看 Netflix
- 吃東西
- 使用筆電
- 商業、科技、金融概念
- 手機與社群媒體

**優點：**

- B-roll 數量多
- 真人情境素材非常符合新聞解說需求
- 搜尋簡單
- 可大量下載

**缺點：**

- 個人方案退訂後，不適合把以前下載的素材拿來製作新的作品
- 不適合「訂一個月下載幾千支，之後一年慢慢用」的策略

---

### Motion Array

偏向完整剪輯工具包。

包含：

- Stock footage
- Music
- Sound effects
- Premiere templates
- After Effects templates
- Transitions
- Lower thirds
- Animated titles
- LUTs
- Plugins

**優點：**

- 非常適合 Premiere / After Effects 工作流
- 做 YouTube 包裝動畫很方便
- 不只有 B-roll

**授權特點：**

一般方案退訂後，不能再把舊素材拿去新的 project 使用。

但 Motion Array 有 **Continuity Plan** 類方案：

- 不再下載新素材
- 仍可繼續使用以前下載的素材製作新作品

這點值得另外研究。

---

### Artlist

適合：

- 電影感畫面
- 高質感紀錄片
- 情緒型 B-roll
- 品牌影片

**優點：**

- 畫質與拍攝品質高
- 音樂庫也很強

**缺點：**

- 價格較高
- 如果只是大量做新聞解說，可能不需要這麼高階

---

### Shutterstock

適合：

- 特定商業畫面
- 很難找到的特定題材
- 公司、產業、醫療、科技類素材

**缺點：**

- 大量使用非常貴
- 不適合每 3 秒換一次 B-roll 的 YouTube 模式

---

### Pond5

適合補：

- 歷史素材
- 特殊地點
- 特殊產業
- 冷門事件
- 新聞感畫面

**重要優點：**

Pond5 的單支授權通常比較接近：

```text
買到授權
→ 可永久使用
→ 不需要持續維持訂閱
```

因此如果某支素材預期會長期反覆使用，可以考慮 Pond5。

---

### Adobe Stock

優點：

- Adobe Premiere / After Effects 整合很好
- 品質穩定

缺點：

- 影片成本高
- 不適合大量下載 B-roll

比較適合偶爾補一支「真的找不到」的重要素材。

## 7. 退訂後授權問題

這一點非常重要。

### Storyblocks

```text
訂閱有效期間下載素材
+ 在有效期間製作 / 發布作品
→ 該作品可以繼續存在

退訂
→ 不應再用以前下載的素材製作新的作品
```

因此不適合：

```text
訂閱 1 個月
→ 下載 1000 支
→ 取消
→ 未來一年慢慢做影片
```

---

### Envato Elements

採用 Project Registration / project license 邏輯。

通常：

```text
訂閱期間
→ 將素材註冊到特定 project
→ 該 project 授權可持續

退訂後
→ 無法再替新的 project 建立新的素材授權
```

---

### Motion Array

一般：

```text
有效訂閱時建立的作品
→ 授權有效

退訂後
→ 舊素材不能直接拿去新的 project
```

但可研究：

```text
Continuity Plan
```

用途：

- 停止下載新素材
- 保留對以前素材的持續使用權

---

### Pond5

單支購買通常最容易理解：

```text
購買素材授權
→ perpetual license
→ 可長期使用
```

因此適合建立少量「核心常用素材庫」。

## 9. Codex 後續可處理的工作

可以讓 Codex 協助建立素材管理系統，例如：

```text
assets/
├── free/
│   ├── pexels/
│   └── pixabay/
├── envato/
├── storyblocks/
├── purchased/
│   └── pond5/
└── metadata/
```

每支素材保存 metadata：

```yaml
asset_id:
source:
source_url:
creator:
download_date:
license_type:
subscription_active_at_download:
project:
keywords:
duration:
resolution:
used_in:
```

並建立 SQLite / CSV 索引，讓後續可以用關鍵字搜尋：

```text
phone scrolling
office
china
american city
money
AI
factory
shopping
social media
```

避免每做一支影片都重新下載相同素材。
