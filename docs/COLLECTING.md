# 素材怎麼收

## 為什麼不能用搜尋

第一次做的時候，我搜尋了一次整個網路，得到零筆有用的結果。原因不是搜尋壞掉，
是問錯問題。

```
搜尋   問「網路上有什麼」  →  回來的東西彼此同意，因為結果第一頁彼此同意
清單   問「這 19 家各說了什麼」  →  每一家都被問到，答案自帶立場
```

第二種還有一個好處：**你知道是誰回答的**，所以立場標籤不用猜。

實測同一個題目，逐家問一輪就拿到右派兩支、中立四支：

```
Fox Business  13.4分  Bond market FLASHES warning      ← 右
Fox News       4.1分  Former Reagan budget director    ← 右
CNBC          12.2分  What Happens If The U.S. Can't Pay
Reuters       10.1分  What does $40 trillion mean       ← 中立
PBS NewsHour   5.6分  National debt nears $40 trillion  ← 中立
```

## 逐家問

影片：YouTube 的頻道內搜尋，yt-dlp 直接吃

```
https://www.youtube.com/@{channel}/search?query={關鍵字}
```

報導：各家自己的搜尋頁，或站內搜尋的網址規則。

清單在 `assets/sources/media.json`，含每家的頻道代號、網站、立場、有沒有付費牆。

## 湊不滿的時候，照順序放寬

一輪不夠就往下一輪，**每一輪都會擴大結果**：

| | 放寬什麼 | 例 |
|---|---|---|
| 1 | 照題目逐家問 | `national debt 40 trillion` |
| 2 | 換關鍵字 | 英文、數字、人名、同義詞 |
| 3 | 放寬日期 | 這週沒有就找這個月 |
| 4 | 放寬題目 | 「40兆」→「國債」。Fox 談國債一樣給得出右派論點 |
| 5 | 跟著引用走 | CNN 引 PGPF、Al Jazeera 引財政部 |
| 6 | 記下失敗 | 「右派試過這些關鍵字，沒有」 |

前五輪是機器做得到的。第六輪不是失敗，是誠實——有些題目就是一面倒，
硬湊反方是假的，而且看得出來。

## 該留下什麼

每一筆都要能回答「這是誰說的」：

```
title      標題
outlet     哪一家（對得上清單，立場才有依據）
lean       立場，從清單查，不是用猜的
url        原始網址
seconds    影片長度
captions   有沒有字幕（決定讀不讀得到內容）
facts      抽出來的事實，每一條都要能指回原文
```

## 鄉民反應

影片和報導底下的留言是**素材的一部分**，不是附屬品。理由：

- 它告訴你**一般人卡在哪裡**——那正是需要解釋的地方
- 它給你**真實的用語**，比新聞稿的說法更接近觀眾
- 它常常包含**新聞沒提的角度**

留言用 yt-dlp 抓（`--write-comments`），報導的留言區各家不同，多半要另外處理。

要留下的：文字、按讚數、時間。**不要留使用者名稱**——那是別人的個資，
我們要的是說了什麼，不是誰說的。

## 一個原則

素材夠不夠，看的不是數量，是**有沒有人不同意**。

五篇彼此同意的報導寫出來是宣傳，八分鐘的影片撐不住，而且 YouTube 的
人工審查會看出來。所以平衡檢查是擋住寫稿的條件，不是提醒。
