## 第 ⑤ 步：機制和產出要分開看

**機制全部正常**：網頁按鈕 → 背景工作 → 送 19.7 KB prompt → 收回 → 抓 JSON →

**Qwen 的產出不能用**，門擋下 11 處：

```
9 句 23.6 秒      要 33 句 90 秒
一張圖都沒挑       49 張擺在面前
簡體中文          連角色都寫成「疑点」「悬念」，公版認不得 → shapeless 擋下
from 亂寫         「真實」「事實」，不是媒體名
最後一句不是 outro
```

**「疑点」那個特別值得記**：那是我沒預想到的失敗方式，而檢查照樣攔下來 ——
門不需要知道那是簡體，只要知道那不是它認識的四個字。

而且有一項不能推給模型：**prompt 從來沒說要繁體**。它照著我給的規則做，
規則裡沒有那一條。

## 一個沒做成的版本

萊比錫原本的角度是 Focus 那篇本身。**做不成**：
逐家問德語媒體，連受訪的 LKA 科長姓名都零筆 —— 那是獨家專訪，沒有人跟進。
單一來源、無人查證、題材是族裔犯罪，硬做就是拿一家的說法當事實。

改成問「那個一千是怎麼數的」，反方就出現了：
BKA 全國年報、上過法庭的案子在北威州和柏林。
**同一批素材，換一個問題，從做不成變成做得成。**

## 審稿那一輪，第一次真的跑了

`critic.read` 本來只接 Anthropic client，所以**它從來沒執行過** ——
程式路徑寫完了，唯一能到達它的東西是一把沒買的金鑰。
改成走 `writer.ask`（跟其他步驟同一條路），今晚在 cuba001 上跑起來。

第一次執行就照抄範例：一支講好萊塢的片子，審稿意見寫
「把『電夠不夠』換成『線夠不夠』」，還說第 14 句的「四十年沒換」找不到出處
—— 那句話不存在。**跟一小時前的相關性判斷是同一個錯。**

現在範例改成 `＜要你填的＞` 佔位符，而且回答如果一字不差出現在 prompt 裡就退回。

改完之後兩份文案都審了，都判 `rewrite`：

| | 意見 | 對不對 |
|---|---|---|
| 好萊塢 | 觀點沒新意，併購在素材裡多次出現 | **有道理** —— 我的角度基本上是 The Economist 那支的角度 |
| 好萊塢 | 第 27 句沒有出處 | 錯，那句是 The Economist 的實拍段落 |
| 萊比錫 | 觀點重複了 Focus 的表述 | **有道理** —— 130／870 那個拆解是原文就有的 |
| 萊比錫 | 「一千是怎麼數的」素材裡找不到 | 錯，那是問句不是陳述 |

各一條有道理、一條錯。`review.md` 自己寫過「你會錯」，
所以 `settle()` 的設計是**報告 verdict，不自動套用** —— 這一輪證明那個設計是對的。

兩條「有道理」指向同一件事：**我的觀點跟最好的那一篇素材太接近。**
那不是門擋得住的，也不是這一輪能修完的。
