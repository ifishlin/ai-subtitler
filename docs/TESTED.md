## 第 5 步：機制和產出要分開看

**機制全部正常**：網頁按鈕 → 背景工作 → 送 19.7 KB prompt → 收回 → 抓 JSON →
把 P18／C3 換成路徑 → 存檔 → 跑九道門。

**Qwen 的產出不能用**，門擋下 11 處：

```
9 句 23.6 秒      要 33 句 90 秒
一張圖都沒挑       49 張擺在面前
簡體中文          連角色都寫成「疑点」「悬念」，公版認不得 → shapeless 擋下
from 亂寫         「真實」「事實」，不是媒體名
最後一句不是 outro
```

**「疑点」那個特別值得記**：那是我沒預想到的失敗方式，而檢查照樣攔下來 ——
門不需要知道那是簡體，只要知道那不是它認識的四個字。

而且有一項不能推給模型：**prompt 從來沒說要繁體**。它照著我給的規則做，
規則裡沒有那一條。
