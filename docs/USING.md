# 做一支短影音，從頭到尾

網頁在 `http://127.0.0.1:8000/scripts`。啟動：

```bash
.venv/bin/python studio/server.py --port 8000
```

底下每一步都標了**現在能不能做**：

```
✅ 網頁上就能做          ⚠️ 部分（缺的地方有寫）        🔑 要 API 金鑰
```

---

## ① 新增題目　✅

右上角輸入名稱 →「新增」。

名稱就是之後所有東西的識別，中英文都可以。

## ② 填兩欄　✅

```
挑這題的理由   為什麼值得花九十秒？有什麼坑？
說給誰聽      結尾整段會寫給這群人聽
```

**「說給誰聽」比看起來重要。** 它會被送進 prompt，而且**決定要收什麼圖**：

```
同一個題目「科技巨頭買下好萊塢」

說給誰聽「付串流訂閱、看新聞的人」   → 要沙發、遙控器、空戲院、帳單
說給誰聽「工作可能被取代的人」      → 要片場、演員、AI 生成的臉
```

**收錯了不會有人擋你**——兩批圖都真的存在、都下載得下來，要到寫結尾的時候
才會發現手上沒東西。

旁邊有時會出現一顆按鈕：`用「加油、繳稅的人」`。那是關鍵字表猜的，**當起頭用，
不是當答案**——它把「好萊塢」猜成「工作可能被取代的人」過。

「挑這題的理由」可以空白。你丟給我的題目本來就沒有「為什麼選它」。

## ③ 收集素材　✅

「收集」那一列，填英文搜尋詞（逗號分隔），按 **逐家問＋下載＋抽畫格**。

一顆按鈕做三件事：

```
逐家問    照 assets/sources/media.json 的 19 家，每家問一輪
下載      合用的抓回來（120–2400 秒、有字幕的優先）
抽畫格    用字幕找到講那件事的秒數，在那裡截圖
```

**為什麼是「逐家問」不是「搜尋」**：搜尋問「網路上有什麼」，回來的東西彼此
同意；逐家問「這 19 家各說了什麼」，**每一家都被問到，答案自帶立場**。

底下的進度條會說它在做什麼。整輪大約三到十分鐘，看影片多長。

跑完之後還可以：

```
抓留言        影片底下的鄉民反應，60 則，不留使用者名稱
找            臨時要一張特定的圖（「我要川普戴帽子的」）
抓這幾個       受眾說會需要、但還沒收到的圖
```

**「抓這幾個」那條琥珀色的列值得看。** 它讀你填的受眾，比對已經收了哪些詞。
數量看不出這件事——三十張片廠照片照樣滿足「15 張照片」，而片子沒有東西
可以結尾。

## ④ 平衡檢查　✅（自動）

不用按任何東西，收集完自己會算：

```
左 ≥ 1　右 ≥ 1　中立 ≥ 2
影片 5　報導 5　照片 15（示意 5、真實 5、新聞畫格 5）
```

不過關就寫不了稿。**驗收條件不是數量，是有沒有人不同意**——五篇彼此同意的
報導寫出來是宣傳，YouTube 的人工審查看得出來。

真的要硬寫，有一顆「素材不齊也要寫」。

## ⑤ 選公版，產生文案　⚠️🔑

```
寫成 [新聞報導 ▾] [產生文案]
```

旁邊會印出那個公版自己寫的理由——「新聞報導 or 說故事」光看兩個字選不出來。

| | 新聞報導 | 說故事 |
|---|---|---|
| 用在 | 電費、戰爭、醫療、石油 | 失竊案、災難、一個人的遭遇 |
| 角色 | 起 承 轉 合 | 場景 事件 疑點 懸念 |
| 轉的時間 | 前 34% 之內 | 沒有限制 |
| 實拍 | 25%，上限 35% | 40%，上限 50% |
| 結尾 | 收成一句判斷 | 收成一個問題 |

**公版要在寫之前選。** 它決定角色、節奏、實拍上限、送哪一份 prompt——事後才
換，每一句都要重標。（梅西納就是這樣重寫了一次。）

標題列的「公版」按鈕可以改這兩個、或新增第三個。

**現在按下去會回 501**：素材、平衡、公版、prompt 全部就緒（17 KB 組得出來），
缺的是模型。設金鑰的位置：

```
~/.config/video_pipeline/anthropic    權限 600，不進版控
```

## ⑥ 看圖確認　✅（由你看）

文案裡每一句用到照片或影片的，旁邊有一個框：

```
[ ] 沒看過        ← 琥珀色
[✓] 看過了        ← 綠色
```

**點縮圖會放大**——列表是拿來找的，放大才是拿來判斷的。卡片的標題字在 1920 高
的畫面上是 76px，在 82px 的縮圖裡就是一團糊。

**為什麼一定要這一步**：程式檢查得了「有沒有指定圖」「檔案在不在」，檢查不了
「像不像」。這個專案第一批圖是憑搜尋詞挑的，`electricity bill` 回來一張牆上的
配電箱被標成「帳單特寫」，兩道檢查都通過，一路走到成品。

沒打勾的會顯示在儀表的「沒看過」，而且**壓片會被擋下來**。

（接上金鑰之後會多一次視覺呼叫先幫你篩，但**它是第二意見，不是取代**——
它標成可疑的還是要有人裁決。）

## ⑦ 編輯　⚠️

能改的：

```
台詞      直接打字，即時顯示字數／秒數／會不會被截掉
角色      下拉，跟著公版換詞彙
說給誰聽   文案自己的一份（跟題目那份可以不同）
公版      換了會警告每一句都要重標
```

**改動不會馬上存**。上面會出現一條琥珀色的列說「N 處未儲存」，按「儲存」才寫進
去。切到別份文案或回題目會丟掉（回題目會先問）。

儲存時會檢查**起承轉合的順序**——單獨看一個角色永遠合理，只有整組排在一起才
看得出「合」跑到「轉」前面。

**還不能在網頁上做的**：換圖、換影片段落、換卡片形狀、增刪句子、調順序。
那些現在要改 `scripts/*.json`。

### 兩個面板值得看

**起承轉合**：四色長條，底下把「轉」的前兩句和後兩句並排——**那是唯一問得出
「理解有沒有變」的形式**。程式證明得了那一句被標成轉、而且在前三分之一；
有沒有翻轉只有讀的人知道。

（這個面板一做出來就抓到梅西納的轉標錯位置，而且真正的問題不是標錯，是節奏
太慢。）

**畫面的權利**：

```
自製 68%　免標示 11%　要標示 0%　有版權 18%
```

**「實拍」不是要看的數字**——圖庫照片是實拍，零風險。要看的是「有版權」那一格，
還有「引用了誰、各幾秒」和「最長一段引用」。合理使用沒有安全的百分比，但審查
最先看的就是這兩個。

## ⑧ 壓片　✅

「壓片」按鈕。約四到五分鐘，進度條會逐句報。

**所有的門在編第一格之前就跑完**：

```
沒指定圖　沒看過　沒畫卡　沒出處　結構　連續太多張長一樣　沒有結尾頁
長度超過 90 秒　會動的不到實拍一半
```

四分鐘的編碼不該花在一份本來就不能發的稿上。

## ⑨ 看接觸表　✅

壓完會多兩顆按鈕：**看接觸表**、**看片**。

接觸表是每個鏡頭一格，**取樣由文案的時間軸決定**——每個鏡頭截它自己長度的
90%，動畫已經停下來的位置。

**這一步不能跳過。** 這個 session 有兩個錯只有排在一起才看得見：

```
結尾連續六張一模一樣的字卡     單張看都沒問題
長條圖的標籤跑出畫面          「算一百年」變成「算一」
```

而且用整數秒截圖會落在動畫中途——我就把正確的「230 億」讀成「119 億」，
還當成影片的錯回報過。

## ⑩ 決定發不發　你

**這一關是設計的一部分，不是還沒做完。** 硬檢查擋得住「有沒有」，擋不住
「好不好」——觀點夠不夠利、那個轉有沒有力、語氣對不對。

發之前還有兩件事要你決定：

```
旁白    自己配音／完全無聲／AI 配音
        AI 配音在健康、財經、政治題材上不能營利
上架    我不建議自動化，那是不可逆的
```

# 十步裡，卡住的有多少

**一步卡住，一步做一半。** 其餘八步網頁上都走得完。

```
⑤ 產生文案     🔑 卡住     按下去回 501。素材、平衡、公版、prompt 全部就緒，
                          17 KB 組得出來，缺的是模型。這是唯一一個
                          「按了不會動」的步驟

⑦ 編輯        ⚠️ 一半     台詞、角色、說給誰聽、公版可以改
                          換圖、換影片段落、換卡片形狀、增刪句子、調順序
                          還要改 scripts/*.json
```

## 這兩件不是缺口，是之後要加的

分開寫，因為併在一起看會以為有四個洞：

```
視覺確認自動化   ⑥ 現在由你打勾就完成了。接上金鑰之後多一次呼叫先幫你篩，
                但它是第二意見 —— 它標成可疑的還是要有人裁決

第二次呼叫審稿   不在這十步裡。它是給「那個轉夠不夠有力」用的 ——
                寫的人相信自己寫的東西翻轉了什麼，那個相信正是他寫下它的
                原因，所以自己審自己不會有分歧。core/critic.py 寫好了，
                沒有金鑰，從來沒跑過
```

還有八件**程式永遠擋不住**的事，寫在 [MISTAKES.md](MISTAKES.md) 的後半——
那份比擋得住的那份重要。
